# Herringbone Parquet

Oak herringbone parquet for the XR gallery floor, from
[Poly Haven](https://polyhaven.com/a/herringbone_parquet): photography by
Sergej Majboroda, processing by Jenelle van Heerden. Released under
[CC0](https://creativecommons.org/publicdomain/zero/1.0/).

The scan covers 3.4 m × 3.4 m and tiles seamlessly. These are Poly Haven's
2K colour and OpenGL normal maps and 1K roughness map, recompressed as JPEG
(quality 92, normal 4:4:4) with metadata stripped.
